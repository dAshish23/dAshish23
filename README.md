## 🚀 Featured projects

### 🔍 AI Missing Person Detection & CCTV Monitoring System
*Team project built at MUJ HackX 4.0 (Manipal University Jaipur), a 36-hour international hackathon, where we reached Round 2.*

Detects missing persons from live CCTV streams and raises alerts only after verifying matches across multiple frames, which cuts false positives.

- **Vision pipeline:** SCRFD face detection → ArcFace embeddings → ByteTrack tracking → FAISS vector search
- **Backend & apps:** FastAPI backend, Flutter mobile app for reporting, desktop edge agent
- **Deployment:** Docker, SQLite offline queue, Hindi/English interface
- 🔗 [HACKX-MUJ](https://github.com/dAshish23/HACKX-MUJ)
